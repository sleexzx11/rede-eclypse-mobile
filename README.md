# Rede Eclypse Mobile — Launcher Android Oficial

Launcher mobile customizado da **Rede Eclypse** para Android, baseado no PojavLauncher com suporte nativo ao **Forge 1.20.1**, Java 17 e auto-update automático de modpack integrado ao GitHub.

---

## 📱 Recursos

- **Nome Oficial:** Rede Eclypse
- **Identificador de Pacote:** `net.redeeclypse.launcher`
- **Versão Padrão:** Minecraft 1.20.1 com Forge 47.4.10
- **Servidor Integrado:** `redeeclypse.srvmc.com` (Rede Eclypse)
- **Auto-Update no Botão Jogar:** Sincroniza mods automaticamente a partir do repositório da Rede Eclypse antes de iniciar o jogo.
- **Compilação Automática (CI/CD):** Ao enviar commits para a branch `main`, o GitHub Actions compila o arquivo `Rede-Eclypse-Mobile.apk` e o disponibiliza na aba **Releases**.

---

## 🛠️ Como Gerar o APK pelo GitHub

1. Envie este repositório para o seu GitHub (ex: `https://github.com/sleexzx11/rede-eclypse-mobile`).
2. Acesse a aba **Actions** no GitHub para acompanhar a compilação.
3. Quando finalizar, baixe o instalador `Rede-Eclypse-Mobile.apk` diretamente na aba **Releases** do repositório.
